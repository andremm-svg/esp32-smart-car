# ESP32 Smart Car

A remote-controlled car built as a university team project in 2024-2025. The project combines embedded programming, wireless communication and basic motor control.

## Hardware

- ESP32 microcontroller
- L298N dual H-bridge motor driver
- Four DC geared motors
- Chassis, power supply and connecting wires

## Software

- C/C++ with Arduino IDE
- ESP32 BluetoothSerial library
- Bluetooth-based remote commands

## How it works

The ESP32 receives movement commands over Bluetooth and translates them into control signals for the L298N motor driver. The driver controls the DC motors to move the car forward, backward, left or right. The implementation also includes a motor stop routine.

## What I worked on

This was a two-student project involving hardware assembly, ESP32 programming, Bluetooth communication and component testing. It helped me apply embedded C/C++ to a working hardware system and understand how software commands affect physical outputs.
